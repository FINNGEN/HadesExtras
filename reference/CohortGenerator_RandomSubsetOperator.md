# Deterministic Random Subset Operator

A cohort subset operator that selects a fixed number of distinct
subjects using a deterministic seed. All cohort rows belonging to
selected subjects are retained. Convert to a list representation

## Super class

[`CohortGenerator::SubsetOperator`](https://ohdsi.github.io/CohortGenerator/reference/SubsetOperator.html)
-\> `RandomSubsetOperator`

## Active bindings

- `numberOfSubjects`:

  Number of distinct subjects to retain.

- `randomSeed`:

  Integer seed used for deterministic subject ordering.
